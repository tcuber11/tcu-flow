Code signing policy

How TCuFlow's downloads are signed, by whom, and how to check one.

What is signed

  • Windows: the installers (x64 and ARM64) are built from this project's source by GitHub Actions and are not code-signed yet, so SmartScreen asks once; check them against SHA256SUMS below.
  • macOS: Developer ID signed and notarized by Apple.
  • Every release: a SHA256SUMS file signed with the TCuFlow release key (public key), and update files signed with TCuFlow's updater key, which the app checks before installing anything.

Only builds of the source in github.com/tcuber11/tcu-flow are signed. Third-party components keep their own licenses and are not re-signed as TCuFlow's work.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it, with one exception: it asks GitHub for the newest release, to offer updates. Everything else it sends goes only to devices you paired with yourself, on your own network. Details: privacy policy.
