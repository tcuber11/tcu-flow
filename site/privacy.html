Privacy

Last updated 4 November 2026

TCuFlow collects no personal data. There is no account, no advertising, no analytics and no tracking. What you share stays between your own devices on your local network.

What moves between your devices

Cursor movement, key presses, clipboard text, pictures and files, and, only when you turn it on, the picture of a screen. They go directly from one of your devices to another over your local network (or a VPN you choose), encrypted with TLS 1.3, and only to devices you paired by confirming the same 6-digit code on both screens. None of it passes through a server of ours; we don't run any.

What stays on each device

  • The device's identity key (in the macOS Keychain, Windows data protection, or the app's private storage on Linux, Android and iOS) and the list of devices you paired with.
  • Your settings, and a small event log in the app's data folder. The log never leaves the device unless you copy it yourself (About → Copy diagnostics).

What reaches the internet

Only the update check: TCuFlow asks GitHub (api.github.com and github.com) for the newest release and, when you update, downloads it from there. GitHub sees that request like any web request, including your IP address; GitHub's privacy statement applies to it. Links you open from the app open in your browser.

Permissions

  • Local network: to find your other devices and talk to them.
  • Accessibility (macOS) or input access (Linux): so a linked device can move the cursor and type on this computer.
  • Screen Recording (macOS): only if you let linked devices view this screen.
  • Wireless debugging (Android): only if you set up the phone to be controlled by a computer.

Children

TCuFlow collects no data from anyone, children included.

Contact

Questions or concerns: open an issue on GitHub. Changes to this page are dated above and kept in the repository's history.
